# C++ 并发世界

## 为什么使用多线程

### 任务分解

耗时操作，任务分解，实时响应。

### 数据分解

充分利用多核CPU处理数据。

### 数据流分解

读写分离，解耦合设计。

### 第一个并发程序

```c++
void ThreadMain() {
	cout << "sub thread id is " << this_thread::get_id() << endl;
	for (int i = 0; i < 10; i++) {
		cout << "sub thread is runing " << i << endl;
		this_thread::sleep_for(chrono::seconds(1));
	}
	cout << "sub thread id is " << this_thread::get_id() << endl;
}
int main(int argc, char** argv) {
	cout << "main thread id is " << this_thread::get_id() << endl;
	//线程启动
	thread th(ThreadMain);
	cout << "wait sub thread" << endl;
	//等待子线程退出 阻塞当前线程
	th.join();
	cout << "sub thread is end" << endl;
	//通过id号区分父子线程
	return 0;
}
```
